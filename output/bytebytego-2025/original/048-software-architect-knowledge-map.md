## Original Extracted Text

Becoming a Software Architect is a journey where you are always learning. But there are some
things you must definitely strive to know.

   1. Master a Programming Language
       Look to master 1-2 programming languages such as Java, Python, Golang, JavaScript, etc.

   2. Tools
       Build proficiency with key tools such as GitHub, Jenkins, Jira, ELK, Sonar, etc.

   3. Design Principles
       Learn about important design principles such as OOPS, Clean Code, TDD, DDD, CAP
       Theorem, MVC Pattern, ACID, and GOF.

   4. Architectural Principles
       Become proficient in multiple architectural patterns such as Microservices,
       Publish-Subscribe, Layered, Event-Driven, Client-Server, Hexagonal, etc.

   5. Platform Knowledge
       Get to know about several platforms such as containers, orchestration, cloud, serverless,
       CDN, API Gateways, Distributed Systems, and CI/CD

   6. Data Analytics
       Build a solid knowledge of data and analytics components like SQL and NoSQL databases,
       data streaming solutions with Kafka, object storage, data migration, OLAP, and so on.

   7. Networking and Security
       Learn about networking and security concepts such as DNS, TCP, TLS, HTTPS, Encryption,
       JWT, OAuth, and Credential Management.

   8. Supporting Skills
       Apart from technical, software architects also need several supporting skills such as
       decision-making, technology knowledge, stakeholder management, communication,
       estimation, leadership, etc.

Over to you - What else would you add to the roadmap?
